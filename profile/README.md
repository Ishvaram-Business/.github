# Ishvaram

**AI Vedic astrology, computed — not guessed.**

[ishvaram.com](https://ishvaram.com) is an AI-first Jyotish platform for India:
free kundali, kundli matching, panchang, choghadiya, rahu kaal and muhurat
tools, plus an AI Jyotish you can talk to in English or Hindi.

## How it's built

Every astronomical fact on the platform — sunrise, tithi, nakshatra, dasha,
muhurat windows — is computed with **Swiss Ephemeris** for the seeker's exact
coordinates and calibrated against independent panchang authorities. The AI
explains; the engine calculates. Our methodology is public:
[ishvaram.com/methodology](https://ishvaram.com/methodology/).

## Open source

We're preparing our first public releases:

- **Panchang widget** — a one-tag embeddable daily panchang / muhurat strip for

- **Panchang API client** — a thin SDK for the free tier of our panchang API.
